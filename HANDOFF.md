## Invariants — every agent must respect

### Routing
- **Builder takes `:id` via path segment** (`/integrations/:id`). The literal
  `'new'` and missing `id` both mean "fresh canvas."
- **Do not reintroduce `?id=` query-param routing.**

  re-route or remove the redirect.
- Top nav has exactly four entries: Dashboard, Integrations, Runs, Mocks.
  Docs lives in the `?` HelpMenu, not the top nav.

### Environment selector
- **Exactly one environment selector** — the global one in the header. Don't
  add a per-canvas selector; the spec says "always visible" and that's already
  satisfied globally.
- Sandbox→Production transition is **gated by a confirm modal**. Production→Sandbox
  is silent.
- For now the selector is global state. When a per-integration `environment`
  field lands on the backend, the selector should *read from* the loaded
  integration on `/integrations/:id` and continue showing the global default
  elsewhere — still one component instance.

### Visual / design system
- **Default to no comments.** Use them only when *why* is non-obvious. Never
  narrate *what*.
- Eyebrow text uses `.eyebrow` class. **Never** redeclare
  `text-[11px] font-mono uppercase tracking-[0.15em]` inline.
- All status pills are `.chip ${tone}` — `chip-success`, `chip-warn`,
  `chip-danger`, `chip-info`, `chip-neutral`, `chip-accent`. No inline color
  on chips.
- Alerts use `.alert` + `.alert-danger` / `.alert-info`.
- The **EmberCanvas** particle field belongs to the Builder canvas only. Do
  not import it elsewhere. Dashboard's NOW strip uses the static
  `NowStripBackdrop` (CSS only).
- Page chrome: `max-w-6xl mx-auto p-6` for list pages with `<PageHeader />`
  on top.

### State / store
- **Focus path** lives in the Zustand store (`useIntegrationStore`). Don't
  lift it back into Canvas.
- **Environment** lives in `useEnvironmentStore` (`stores/environment.ts`).
  Persisted under `localStorage` key `solder-environment`.
- **Theme** lives in `useThemeStore`. Persisted under `solder-theme`.

### Builder canvas
- **Container nodes never expand inline.** Body is reachable only via
  step-into. The compact branch-row is the visible affordance.

  React tick so the camera zoom has the right origin.
- DnD MIME types: `application/x-solder-existing` (move),
  `application/x-solder-new` (palette). Defined in

  Stable.
